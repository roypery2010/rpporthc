0.0.2

    Introduced three convenience flags to the compiler:
    -s             Silent mode. Don't print any info about compilation phases.
    -r             Run the program after successful compilation.
    -m <capacity>  The size of the memory buffer in bytes to allocate for the
                   bf program runtime. (Default: 1024)
